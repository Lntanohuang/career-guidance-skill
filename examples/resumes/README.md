# 高职在校生简历样例

本目录提供给 `career-guidance` 做岗位匹配、证据改写和缺口识别的合成测试材料。

- 所有姓名、学校、项目、数字和联系方式均为演示数据，不对应真实求职者。
- 使用前应替换为本人已确认的事实；无法核验的指标只能保留为“待补证据”。
- 样例覆盖计算机运维、智能制造、电子商务、生产制造、运营和销售六个方向；前三份按在校生/应届生场景编写，后后三份对应岗位库中占比最高的三个职业类别。

| 文件 | 方向 | 适合测试的重点 |
|---|---|---|
| [01-计算机网络技术-运维实习.md](01-计算机网络技术-运维实习.md) | 网络运维 / IT 技术支持 | 故障排查、工单、证书与项目证据 |
| [02-机电一体化-设备技术员.md](02-机电一体化-设备技术员.md) | 设备技术员 / PLC 助理 | 课程项目、现场安全、可迁移技能 |
| [03-电子商务-运营实习.md](03-电子商务-运营实习.md) | 电商运营 / 直播运营 | 内容生产、数据复盘、作品集缺口 |
| [04-生产制造类.md](04-生产制造类.md) | 生产制造 | 生产计划、工艺工程、质量管理 |
| [05-运营类.md](05-运营类.md) | 运营 | 电商运营、用户运营、内容运营 |
| [06-销售类.md](06-销售类.md) | 销售 | 大客户销售、销售工程、渠道销售 |
