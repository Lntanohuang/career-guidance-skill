# 岗位库数据源文档（高职切片口径）

> 用途：career-guidance 技能引用岗位市场数据给高职（大专）客户做就业建议时的数据源说明与复现手册。
> 数据快照日期：**2026-09-20**。本文所有数字均来自该日快照的全量精确计数（另有注明者除外）。
>
> **引用原则（最高优先，用户口径）**：本库信息不全面——来源以 BOSS直聘为主（核心切片 89.6%）、无真实发布时间、行业与企业覆盖有偏，**绝对条数不代表市场总量**。给建议时只引用**比例与结构**（学历占比、薪资分桶占比、岗位名排序、地域占比、经验分布），绝对条数仅作库内量级参考，不得外推为"全国有 X 个岗位"之类的结论。

## 1. 连接方式（只读）

```bash
MYSQL_PWD='read@123456' mysql -h 192.168.8.1 -P 3908 -u tringai_read \
  --default-character-set=utf8mb4 -D ai_crowd_souring_extend
```

注意事项（都是踩过的坑）：

- 密码含 `@`，必须用 `MYSQL_PWD` 环境变量传，不能写在命令行参数里。
- 账号仅对 `ai_crowd_souring_extend` 库有 SELECT 权限，**只读，切勿写库**。
- 每个会话先执行 `SET NAMES utf8mb4 COLLATE utf8mb4_general_ci;`，否则中文输出变 `?`。
- 表注释在 `SHOW CREATE TABLE` 里是乱码，查 `information_schema.columns.column_comment` 代替。
- 主表 `c_company_position` 约 1,156 万行 / 15.7GB，`description` 是 longtext——**永远不要 SELECT description**。
- FULLTEXT 索引对中文无效，中文岗位名只能 LIKE（全表扫）；拿热门岗位名用 `GROUP BY name`，不要 LIKE。
- 全表 GROUP BY 聚合单条约 50–70 秒可完成；给查询加 `SET SESSION max_execution_time=200000;`（毫秒）兜底，超 3 分钟就降级抽样。

## 2. 核心表与字段

| 表 | 行数（约） | 用途 | 关键字段 |
|---|---|---|---|
| `c_company_position` | 1,156 万 | 岗位主表 | `id`、`name`(岗位名)、`education`、`experience`、`min_salary`/`max_salary`(varchar, K/月)、`publish_state`、`deleted`(bit)、`data_source`、`company_address_id`、`company_archive_id`、`create_time`(爬虫批次时间) |
| `c_company_address` | — | 公司地址 | `id`、`province`、`city`、`district`（province 有索引） |
| `c_position_chain` | 2,100 万 | 岗位×产业链关联 | `position_id` + `industry_chain_id` 唯一，`position_id` 有索引 |
| `c_industry_chain_info` | 1.3 万 | 产业链名称/层级 | `id`、`name`、`pid`/`pids`/`level`(0–4 层级树) |

关联关系：`c_company_position.company_address_id = c_company_address.id`；`c_company_position.company_archive_id = c_company_address.company_id = c_company_archive.id`；`c_position_chain.position_id = c_company_position.id`。

在招口径（所有统计的前提）：`publish_state='PUBLISHING' AND deleted=0`，快照日共 **9,616,999** 条。

## 4. 高职切片口径定义（引用数据时必须二选一并注明）

- **高职核心切片**（下称"核心"）：`education IN ('DAZHUAN','GAOZHI')` —— 岗位明确要求大专/高职学历。快照值 **2,678,591 条（占在招 27.9%）**。
- **高职可投宽口径**（下称"宽口径"）：核心 + `ZHONGZHUAN/ZHONGJI` + `GAOZHONG` + `BUXIAN`，即学历门槛低于或等于大专的全部岗位（高职生可投）。快照值 **7,154,762 条（占在招 74.4%）**。
- 给"高职生能投什么"的建议用宽口径；给"明确面向大专的岗位"画像用核心切片。两者差距主要来自"不限学历"的 336 万条。

## 5. 核心结论数字（快照 2026-09-20）

- **量级**：在招 961.7 万；核心切片 267.9 万（27.9%）；宽口径 715.5 万（74.4%）。
- **薪资（核心切片，中值=(min+max)/2，K/月）**：中位 **6.6K**（全量 7.0K），P25–P75 = 4.9K–9.4K；分布：3–6K 占 32.6%、6–10K 占 40.3%、10–15K 占 16.2%、15–25K 占 6.5%、25K+ 占 1.5%、<3K 占 2.8%。99.9% 的核心岗位有数值薪资。

- **经验（核心切片）**：不限 20.5%，3 年以内 41.7%，1 年以内 5.2%，5 年以内 23.0%；≤3 年或应届/在校合计约 67%。

## 6. 复现 SQL 全文（均已在快照日跑通，单条 ≤70 秒）

```sql
SET NAMES utf8mb4 COLLATE utf8mb4_general_ci;

-- Q1 学历分布（全量精确，兼得切片基数）
SELECT education, COUNT(*) AS cnt
FROM c_company_position
WHERE publish_state='PUBLISHING' AND deleted=0
GROUP BY education ORDER BY cnt DESC;

-- Q2 高职核心切片岗位名 TOP50
SELECT name, COUNT(*) AS cnt
FROM c_company_position
WHERE publish_state='PUBLISHING' AND deleted=0
  AND education IN ('DAZHUAN','GAOZHI')
GROUP BY name ORDER BY cnt DESC LIMIT 50;

-- Q3a 薪资中值分布（grp: core=大专+高职 / wide_rest=中专+高中+不限 / above=本科及以上；
--     分桶与分位数在 python 侧由该分布计算；mid=(min+max)/2，CAST 后空/非数值记 0）
SELECT grp, rmid, COUNT(*) cnt FROM (
  SELECT grp, ROUND(mid,1) AS rmid FROM (
    SELECT CASE WHEN education IN ('DAZHUAN','GAOZHI') THEN 'core'
                WHEN education IN ('ZHONGZHUAN/ZHONGJI','GAOZHONG','BUXIAN') THEN 'wide_rest'
                ELSE 'above' END AS grp,
           (COALESCE(CAST(min_salary AS DECIMAL(10,2)),0)
            +COALESCE(CAST(max_salary AS DECIMAL(10,2)),0))/2 AS mid
    FROM c_company_position WHERE publish_state='PUBLISHING' AND deleted=0
  ) t1
) t2 GROUP BY grp, rmid ORDER BY grp, rmid;

-- Q3b 薪资字段形态核查（口径注记用）
SELECT grp, sal_form, COUNT(*) cnt FROM (
  SELECT CASE WHEN education IN ('DAZHUAN','GAOZHI') THEN 'core'
              WHEN education IN ('ZHONGZHUAN/ZHONGJI','GAOZHONG','BUXIAN') THEN 'wide_rest'
              ELSE 'above' END AS grp,
         CASE WHEN min_salary IS NULL THEN 'NULL' WHEN min_salary='' THEN 'empty'
              WHEN CAST(min_salary AS DECIMAL(10,2))=0 THEN 'zero' ELSE 'numeric' END AS sal_form
  FROM c_company_position WHERE publish_state='PUBLISHING' AND deleted=0
) t GROUP BY grp, sal_form;

-- Q3c TOP20 热门岗位的中值薪资分布（IN 列表来自 Q2 前 20 名，中位数 python 侧算）
SELECT name, rmid, COUNT(*) cnt FROM (
  SELECT name, ROUND(mid,1) AS rmid FROM (
    SELECT name,
           (COALESCE(CAST(min_salary AS DECIMAL(10,2)),0)
            +COALESCE(CAST(max_salary AS DECIMAL(10,2)),0))/2 AS mid
    FROM c_company_position
    WHERE publish_state='PUBLISHING' AND deleted=0
      AND education IN ('DAZHUAN','GAOZHI')
      AND name IN ('室内设计','平面设计','新媒体运营', /* …TOP20 逐个列出… */)
  ) t1 WHERE mid > 0 AND mid <= 100
) t2 GROUP BY name, rmid ORDER BY name, rmid;

-- Q4 经验要求分布（按组）
SELECT CASE WHEN education IN ('DAZHUAN','GAOZHI') THEN 'core'
            WHEN education IN ('ZHONGZHUAN/ZHONGJI','GAOZHONG','BUXIAN') THEN 'wide_rest'
            ELSE 'above' END AS grp,
       experience, COUNT(*) cnt
FROM c_company_position WHERE publish_state='PUBLISHING' AND deleted=0
GROUP BY grp, experience;

-- Q5a 核心切片省份分布（join 地址表，覆盖 99.95%）
SELECT a.province, COUNT(*) cnt
FROM c_company_position p JOIN c_company_address a ON p.company_address_id=a.id
WHERE p.publish_state='PUBLISHING' AND p.deleted=0
  AND p.education IN ('DAZHUAN','GAOZHI')
GROUP BY a.province ORDER BY cnt DESC;

-- Q5b 广东省内城市分布（province 走索引）
SELECT a.city, COUNT(*) cnt
FROM c_company_position p JOIN c_company_address a ON p.company_address_id=a.id
WHERE p.publish_state='PUBLISHING' AND p.deleted=0
  AND p.education IN ('DAZHUAN','GAOZHI') AND a.province='广东省'
GROUP BY a.city ORDER BY cnt DESC;

-- Q6 数据来源分布（按组）
SELECT CASE WHEN education IN ('DAZHUAN','GAOZHI') THEN 'core'
            WHEN education IN ('ZHONGZHUAN/ZHONGJI','GAOZHONG','BUXIAN') THEN 'wide_rest'
            ELSE 'above' END AS grp,
       COALESCE(data_source,'(NULL)') AS data_source, COUNT(*) cnt
FROM c_company_position WHERE publish_state='PUBLISHING' AND deleted=0
GROUP BY grp, data_source ORDER BY grp, cnt DESC;

-- Q7 产业链 TOP（岗位×链关联数，一岗多链；建议加 max_execution_time 兜底）
SET SESSION max_execution_time=200000;
SELECT ic.name, ic.level, COUNT(*) cnt
FROM c_company_position p
JOIN c_position_chain pc ON pc.position_id=p.id AND pc.deleted=0
JOIN c_industry_chain_info ic ON ic.id=pc.industry_chain_id
WHERE p.publish_state='PUBLISHING' AND p.deleted=0
  AND p.education IN ('DAZHUAN','GAOZHI')
GROUP BY ic.name, ic.level ORDER BY cnt DESC LIMIT 15;

-- Q7b 产业链覆盖率
SELECT COUNT(*) AS link_cnt, COUNT(DISTINCT pc.position_id) AS pos_cnt
FROM c_position_chain pc JOIN c_company_position p ON pc.position_id=p.id
WHERE p.publish_state='PUBLISHING' AND p.deleted=0
  AND p.education IN ('DAZHUAN','GAOZHI') AND pc.deleted=0;
```

薪资统计口径细则：分桶为 `<3K / 3-6K / 6-10K / 10-15K / 15-25K / 25K+`，剔除中值=0（面议/空值，核心切片 0.07%）与中值>100K（脏值，核心切片 0.03%）后计算；分位数用加权线性插值。

## 7. 数据局限（引用时须知）

1. **create_time 是爬虫抓取/变更批次时间，不是岗位真实发布时间**；月度趋势只能反映数据更新节奏，不可当招聘季节性用。
2. **岗位无原始职位链接**（库内无可回溯 URL），无法下钻验证单条岗位详情。
3. 薪资为抓取时点的区间值（varchar，K/月），存在少量脏值（中值>100K）与非数值（空串/NULL 记 0）；历史口径提到的"启信宝来源无薪资"在本次在招快照的核心切片中未出现启信宝来源（主力为 BOSS直聘 89.6%），无薪资行合计仅 0.1%，影响可忽略。
4. 学历/经验/薪资字段是岗位 JD 声明值，未经核实；同一岗位可能多来源重复抓取（data_source 维度可见 BOSS直聘 绝对主导）。
5. province 字段有少量脏值（如"石家庄市"19 条、"河北"4 条，量级可忽略）；address join 覆盖 99.95%。
6. "高职"（GAOZHI）枚举极少（798 条），学历维度实质以"大专"承载高职层次——口径见第 4 节。
7. 产业链计数是**岗位×链关联数**（一岗平均 2.07 链），不是去重岗位数；链表为 0–4 级树，TOP 聚合未归并到统一层级（TOP 结果多为 3–4 级细链）。
8. 快照为时点数据（2026-09-20），在招岗位随批次滚动更新，引用超过一个季度建议重跑第 5、6 节查询刷新数字。
