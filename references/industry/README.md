## 使用规则

1. **优先本地**：回答产业/就业/薪酬/政策类问题前，先读对应篇目；本目录已覆盖常用维度与口径说明。
2. **缺失才联网**：以下情况才联网检索，并在回答中标注检索日期与来源——(a) 具体城市/院校/企业实时岗位与薪资；(b) 某省当年专升本计划、补贴细则；(c) 2026-09 之后的政策与数据更新。
3. **口径纪律**：每个数字引用时保留来源标注（机构/报告/届别或年月）；缺口数字区分"规划预测/行业自估/实时监测"；薪酬区分"毕业半年后月收入（麦可思）"与"签约月薪（招聘平台）"，不得混用。
4. **已知数据缺口**（联网时优先补）：人社部"最缺工"排行 2025 年度及以后各期；智联 2025/2026 就业力调研全国数字；人社部 2025+ 全国工资指导线汇总；托育行业全国缺口精确数；高职分城市线级起薪。
5. **保守引用**：数字给区间/约数，不外推、不跨口径比较；查不到就写"未检索到公开数据"。
