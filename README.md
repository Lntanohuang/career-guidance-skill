# career-guidance

`career-guidance` 是面向学生、求职者和职业转型者的 Codex Skill。它将目标、经历、岗位要求和现实约束整理成职业定位、岗位匹配、简历改进、求职行动计划和 offer 评估。

## 安装

```bash
git clone https://github.com/Lntanohuang/career-guidance-skill.git
```

在本地 Skill 广场中，推荐通过 Git submodule 挂载到 `.agents/skills/career-guidance`。

## 示例

```text
使用 $career-guidance，目标是 Java 后端实习。请根据我的匿名简历和岗位描述，列出岗位匹配证据、三个关键缺口和 30 天行动计划。
```

Skill 会区分用户事实、岗位原文、推断和待核实信息，不编造经历或承诺录用结果。
