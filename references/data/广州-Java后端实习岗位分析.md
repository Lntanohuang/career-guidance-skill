## 1. 查询口径

- 工具：`node scripts/career-market-query.mjs`（白名单 queryId，无原始 SQL；本机需 mysql 8.x 客户端，已由 `scripts/mysql-client.mjs` 自动回落）
- 城市：广州市（`c_company_address.city`）
- 在招：`publish_state='PUBLISHING' AND deleted=0`
- 岗位名筛选：`name LIKE '%Java%'` AND (`name LIKE '%后端%'` OR `'%服务端%'` OR `'%开发%'`)。**口径限制**：只覆盖岗位名里带“Java”的岗位，不含仅写“后端/服务端实习”的岗位，样本量偏低估。
- 两套口径分别统计，不混合：
  - **实习口径**（`internship=true`）：岗位名含“实习/intern” **或** `experience IN ('GRADUATING','ON_CAMPUS')`
  - **在招口径**（`internship=false`）：广州 Java 后端全部在招岗位，作对照背景
- 查询时间：2026-09-28；库内数据快照：2026-09-20（在招口径滚动更新）
- 样本量：实习口径 **10** 条；在招口径 **329** 条（有效薪资 328 条）

## 3. 关键结论

1. **学历门槛是主要硬约束**：实习口径 10 条全部标“本科”，大专生在“岗位名含 Java 的实习岗”里没有一条明确开放；把范围放到广州 Java 后端在招全量，仍有 12.5% 明确写大专，说明机会存在于中小公司/非实习命名岗位，而不是主流实习标签。
2. **实习样本极薄**：10 条不足以支撑稳定的岗位画像，任何实习口径百分比都只能当“目录抽样”，不能当广州实习市场结构。
3. **在招整体薪资与实习薪资断层明显**：在招口径主力区间 10–25K（合计 64%），实习口径过半样本落在 6K 以下，符合实习薪酬特征。
4. 实习口径经验分布（在校/应届/不限）与筛选条件部分同义，不能作为“实习岗经验门槛低”的独立证据。
